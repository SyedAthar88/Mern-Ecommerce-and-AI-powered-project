# MERN Ecommerce (in progress)

Full-stack authentication + admin panel built with the MERN stack.
Currently converting to an AI-powered ecommerce platform.

## Tech Stack

**Backend**
- Node.js + Express 5
- MongoDB + Mongoose 9
- JWT (access + refresh tokens)
- bcrypt, Zod, Nodemailer
- Helmet, CORS, express-rate-limit

**Frontend** (coming soon)
- React + Vite
- React Router
- Axios
- Context API
